AI model · reads and writes

Groq · openai/gpt-oss-120b

Used by
understand_comment and write_answer in the ask graph; spot_products in the post graph. The short thank-you and hand-off texts come from the same reading call.
Settings
A strict JSON schema on every call, reasoning effort low, at most 1,000 output tokens (GROQ_MAX_TOKENS, 300 to 4,000).
Free tier
30 requests and 8,000 tokens a minute; 1,000 requests and 200,000 tokens a day. The job drafts one comment at a time and waits out a 429 for the time Groq gives.
The model
OpenAI's open-weight mixture-of-experts model: 117B parameters, 5.1B active per token (4 of 128 experts), 128K context, Apache 2.0. It reads text only, so a post is read from its caption.
Without a key
Rules read comments and captions; templates write the replies.

AI model · search by meaning

Jina · jina-embeddings-v5-text-small

Used by
The index (all 436 names in one call at upload) and find_entities (the comment's product and place words).
Settings
256 numbers per text (the model is trained so 1,024 can be cut to 256), task text-matching, vectors normalized and stored as base64 Float32.
The model
677M parameters, built on Qwen3-0.6B, 1,024 dimensions, 119+ languages, 32K-token context.
Without a key
Search runs on BM25 and character vectors, as on this page.

Method · search by words

BM25

k1 = 1.2, b = 0.75. Each Arabic word is also indexed without its prefixes (و, ب, ل, ك, ف, ال), so بالزرقا meets الزرقا. A word found in fewer names weighs more.

Method · search by spelling

Character vectors

Every piece of 2, 3 and 4 letters, with # at the word edges, is hashed (FNV-1a) into one of 512 slots; longer pieces weigh more; the vector has length 1. A typo keeps most pieces: زيتوون and زيتون score 0.81.

Method · one ranking from three

Reciprocal rank fusion

score = Σ 1 / (60 + rank) over the rankings, plus 0.05 for an exact name. Ranks need no tuning of score scales between BM25, cosines and Jina.

Framework · runs the steps

LangGraph.js

Two StateGraphs with typed channels. The post graph has 4 nodes; the ask graph has 11 nodes, 3 conditional routers, 9 fixed edges and 20 state channels. If LangGraph cannot load, the same definition runs on a small built-in runner.

What runs on this page. The console's own ingest, hybrid search (BM25 and character vectors), table query, rules, templates, fact check and both graph definitions, bundled from the same source files as the Netlify functions.

What does not. Groq and Jina need keys. Here the graphs read with the backend's rules and write with its templates, and search fuses two rankings instead of three. The graphs run on the backend's built-in runner, which executes the definition LangGraph compiles on Netlify.

The data. The sample pos_availability.csv from the brief: 936 shelf visits from 12 to 25 August 2026, 40 shops, 27 products.
